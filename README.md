# Important Commands
- `TSInstall <arg>` install tree-sitter for arg
- `Mason` open mason menu

# Important shortcuts
| Keybind | Description |
|-|-|
| `<leader>e` | Explore Files |
| `<leader>ff` | Find File |
| `<leader>fw` | Find Word |

# Font

I use [CodeNewRoman](https://www.nerdfonts.com/font-downloads) in my terminals
